Release checklist (maintainer notes)

Build:
1. Bump CFBundleShortVersionString / CFBundleVersion in SideButtonFixer/Info.plist
2. Xcode → Product → Archive (SensibleSideButtons scheme)
3. Export Developer ID build; confirm: lipo -archs …/SensibleSideButtons

Notarize:
1. ditto -c -k --keepParent SensibleSideButtons.app SensibleSideButtons.zip
2. xcrun notarytool submit … --wait
3. xcrun stapler staple SensibleSideButtons.app

DMG:
1. Replace .app in existing DMG or create new folder image with Applications symlink
2. hdiutil convert -format UDZO …

Defaults (debug):
  defaults read net.archagon.sensible-side-buttons
  defaults delete net.archagon.sensible-side-buttons

Verify signing:
  codesign -dvvv SensibleSideButtons.app
  codesign --verify --deep --strict --verbose=2 SensibleSideButtons.app
